# Установка personal-board (Consilium) под не-технического пользователя

Цель скилла: пользователь сказал «собери мне доску» — и через несколько минут у него
рабочий совет хотя бы из одного **грунтованного** советника, БЕЗ ручного редактирования
JSON, без `pip install`, без терминала. Зависимостей у пола нет — лексический ретрив и
защитный контур (verbatim-проверка цитат) это чистый Python stdlib.

**Чем это отличается от «чат-бота в роли мудреца» (и почему контур — суть):** советник
цитирует ТОЛЬКО дословно из верифицированного корпуса (🔵), всё остальное помечает как
перенос (🟡); на вопрос вне корпуса — честно отказывается, а не фантазирует. Этот контур
работает **на любом тире, даже на 0-install полу** — деградирует только качество ретрива,
не честность. Поэтому «минимальный кит» — честный минимум, а не кастрат.

**Два тира (скилл сам выберет на `board_init`):**
- **ПОЛ (SIMPLE)** — лексический ретрив + verbatim-гейт цитат. Нужен только Python 3.10+. Ноль установки сверх скилла.
- **FULL** — семантический ретрив (bge-m3 через ollama). Нужен живой ollama на машине пользователя. Опционально, для большого корпуса.

**Доска пустая из коробки — это норма.** `advisors/` это твои личные данные (в .gitignore),
скилл их не везёт. Совет ты собираешь сам — Шаг 3 ведёт за руку. Кого посадить — выбор
пользователя.

---

## Шаг 0 — ОПРЕДЕЛИ СРЕДУ (критично, не пропускай)

От среды зависит, что ты делаешь сам, а где только ведёшь. Будь честен про границу: НЕ обещай того, что среда физически не может.

Проверка: `pwd && uname -a && whoami`.

### Ты в Claude Code (или локальном CLI, где bash = реальная машина пользователя)

Домашняя папка пользователя на его ОС (macOS/Windows/Linux), не контейнер. Делаешь ВСЁ сам:
ставишь скилл, гонишь `board_init`, собираешь советников (Шаг 3), прогоняешь `eval`. Иди 1→4.

### Ты в Cowork (bash = изолированная Linux-песочница)

Признак: `uname -a` — Linux-контейнер, домашняя папка вида `/home/...` или `/sessions/...`,
имя пользователя не совпадает с реальным.

**ВАЖНО — и тут мы выгоднее MCP-серверов:** наш пол это чистый Python, ему не нужен ни
хостовый конфиг, ни ollama, ни ключи. Поэтому в Cowork ты МОЖЕШЬ полностью собрать рабочую
доску (пол) **прямо в подключённой папке пользователя**: `collect_* → build_advisor →
persona.md → eval` всё исполняется в песочнице. Чего песочница НЕ может:
- включить **FULL-тир** (ollama живёт на хосте) — останется пол (контур всё равно работает);
- **прописать скилл в Claude-клиент пользователя** для будущих сессий (это на хосте).

Так что в Cowork: собери доску-пол в подключённой папке здесь и сейчас; для FULL-тира и для
постоянной установки скилла — доведи пользователя до Claude Code / локального запуска. Не
делай вид, что включил семантику или прописал скилл на хост, если ты в песочнице — скажи прямо.

## Шаг 1 — Получить скилл на машину пользователя

Разумная папка: `~/personal-board` (macOS/Linux) или `%USERPROFILE%\personal-board` (Windows).
В Cowork — подключённая папка пользователя.

> ⚠️ **В Cowork НЕ клонируй прямо в подключённую папку** — хостовое FUSE-монтирование не
> поддерживает git file-locking (`unable to unlink '.git/config.lock': Operation not
> permitted`). Клонируй в песочницу и копируй БЕЗ `.git`:
> `git clone … /tmp/pb && rm -rf /tmp/pb/.git && cp -R /tmp/pb/. <папка>/`.
> Чаще клонировать не надо — папку со скиллом просто подключают.

**Установка скилла (для будущих сессий, локально):** скопируй каталог скилла в место, где
Claude его подхватывает (Claude Code: `~/.claude/skills/<имя>/` либо как плагин). Минимум —
работай прямо из папки скилла: все скрипты самодостаточны (consumers добавляют только
`scripts/` в путь, движок — пакет с относительными импортами).

Проверка Python (нужен 3.10+): `python3 --version` (Windows: `py -3 --version`). Нет — см. Troubleshooting.

## Шаг 2 — Определить тир (board_init)

`board_init` считает размер корпуса каждого советника и проверяет, доступна ли семантика,
и пишет `board_config.json` (тир на советника + калиброванные пороги + chunk_chars). Ничего
не ломает, повторный запуск безопасен.

Сначала проверь ollama (FULL-тир). Из папки скилла:
```bash
python3 -c "import sys; sys.path.insert(0,'scripts'); from engine.semantic import SemanticEngine; print('semantic:', SemanticEngine.available())"
```
- `True` → семантика есть: `python3 scripts/board_init.py advisors --semantic-available true`
- `False` → пол: `python3 scripts/board_init.py advisors --semantic-available false`
  (Это НЕ ошибка. Контур работает, цитаты 🔵 проверяются дословно — просядет только меткость ретрива. Если хочешь FULL: поставь ollama + `ollama pull bge-m3`, потом перезапусти этот шаг.)

На свежей пустой доске board_init просто покажет 0 советников — это нормально, идём в Шаг 3.

## Шаг 3 — Собрать первого советника (сердце; заменяет «ключи» у MCP)

Это разговорный рецепт. Спроси: **кого пользователь хочет на доске?** (мыслитель, живой или нет).
Дальше маршрут грунтовки зависит от того, кто это:

**A. Public domain (умершие, классические тексты)** — Аврелий, Макиавелли, Сенека, Сунь-Цзы…
`collect_pd` тянет с Gutenberg/Wikisource (PD-хосты подтверждаются авто). Ты сам находишь URL.
```bash
python3 scripts/collect_pd.py advisors/<slug> --url <gutenberg-url> --name <source-slug>
```

**B. Живые / современные** — эссе, выступления, посты. `collect_web` / `collect_transcript`
(personal-use гейт). ЛИБО пользователь кладёт **легальные копии** книг в `advisors/<slug>/sources/`.
> ⚖️ **Легальная граница (несущая):** скилл НЕ качает копирайтные книги. PD — свободно через
> `collect_pd`. Копирайт — только легальные копии, которые предоставляет пользователь, в
> `sources/` (он в .gitignore, чужие тексты не коммитим и не редистрибутируем).

**C. Язык.** Корпус всегда в АУТЕНТИЧНОМ языке автора (перевод корпуса убил бы verbatim).
Запрос при ретриве переводится в язык корпуса (язык-агностично, не целимся в один язык).
Русскоязычный-натив (его подлинный корпус русский) → одноязычная пара, лучшая точность даром.

### Рецепт (то, что делается на каждого советника)

1. **Собрать источник** (A/B выше) → `advisors/<slug>/sources/`.
2. **Построить корпус:**
   ```bash
   python3 scripts/build_advisor.py advisors/<slug> --name "<Имя>" --max-quotes 40
   ```
   → `corpus.jsonl` + `quote_candidates.md` (кандидаты ШУМНЫЕ — включают вступление редактора; бери дословно только из ТЕЛА).
3. **Написать `advisors/<slug>/persona.md`** — структуру повторяй с уже собранного советника (или см. `advisors/README.md`):
   - frontmatter: `name, aliases, domains, lenses, consent_status, fidelity, role_framing`
   - `role_framing` — **3-е лицо** (снижает sycophancy): советник держит свою линзу и скорее оспорит, чем поддакнет.
   - `## Конституция` (от 1-го лица, ядро голоса) · `## Как спорит` · `## Чего не делает (never_do)` + `never_quote` (явно перечисли известные ФЕЙК-цитаты этой фигуры) · `## Quote bank` (🔵) · `## Где challenge-ит` (под задачу пользователя).
4. **ПРОВЕРИТЬ КАЖДУЮ цитату банка контуром** (это и есть ров — не пропускай):
   ```bash
   python3 -c "import sys; sys.path.insert(0,'scripts'); from engine.fidelity import best_match; print(best_match('<точная цитата>', 'advisors/<slug>'))"
   ```
   Вернулось `('P1'|'P2', источник)` → ставь 🔵. `('S1'|'S2', …)` → это **комментарий** (не слова автора): максимум 🟢 с именем комментатора, НИКОГДА не 🔵 голосом советника. `('B'|'A', …)` (front-matter/апокриф) или `None` → цитата не годится: поправь до точного текста ТЕЛА автора или выкинь. **НИКОГДА не помечай 🔵 непроверенное или комментарий.** (Языко-корпусный трюк для ретрива: ищи запросом на языке корпуса.)
5. **Тир + конфиг:** `python3 scripts/board_init.py advisors --semantic-available <true|false>`.
6. **Если FULL-тир** (большой корпус + ollama): построить семантический индекс —
   ```bash
   python3 scripts/tier_full.py advisors/<slug>
   ```
7. **Проверить:** golden-набор в `scripts/golden/<slug>.{retrieval,abstention}.jsonl` (по образцу существующих) + `python3 scripts/eval.py advisors/<slug>`.

Хочешь больше голосов — повтори рецепт. Против эхо-камеры: `python3 scripts/diversity_check.py`
(следит, чтобы советники не слиплись в один тембр).

## Шаг 4 — Проверка (доказательно, не по самоотчёту)

> Стандарт: успех доказывается **живым прогоном**, а не «я всё сделал».

1. **Какой тир активен:** `python3 scripts/doctor.py` — печатает FULL/SIMPLE и подтверждает, что контур работает на полу.
2. **Контур + честность:** `python3 scripts/eval.py advisors/<slug>` — должно дать `🔵 verified X/X (100%)`, CORRECTNESS без нарушений, ABSTENTION 0 галлюцинаций. Если 🔵 не 100% — в банке есть непроверенная цитата (вернись к Шагу 3.4).
3. **Боевой вызов:** созови советника на реальный вопрос пользователя — в ответе должны стоять 🔵/🟡, а на вопрос вне корпуса должен быть честный отказ. Это и есть доказательство.

## Troubleshooting

**«Python не установлен» / `command not found: python3`:** поставить Python 3.10+ с python.org. Windows — галочка «Add python.exe to PATH», потом новый терминал.

**Семантика недоступна / нет ollama:** это НЕ блокер. Остаёшься на полу — контур и 🔵-цитаты работают, просядет только меткость ретрива. Хочешь FULL: `ollama pull bge-m3`, живой ollama на :11434, перезапусти Шаг 2.

**Цитата вернула `None` (не 🔵):** она не дословна в корпусе. Сверь по источнику (`grep -nF "…" advisors/<slug>/sources/*.txt`), поправь до точного текста или убери. Не форсить 🔵 — это ломает весь смысл.

**Кандидаты-цитаты — мусор (заголовки глав, вступление редактора):** бери verbatim только из ТЕЛА произведения, не из предисловия переводчика.

**Ретрив тематически близко, но не точно (кросс-язык):** известный эффект на большом однородном кросс-язычном корпусе. Контур (🔵/отказ) от этого не страдает — страдает меткость. Фикс: ретрив запросом на языке корпуса; либо советник-натив языка пользователя.

**Доска пустая:** так и должно быть на свежей установке. Собери советника Шагом 3.

**`git clone` падает в Cowork (`Operation not permitted` / `config.lock`):** FUSE-монтирование. Клонируй в `/tmp`, копируй без `.git` (см. Шаг 1).

## Памятка: что зависит от среды (anti-overpromise)

- **Claude Code / локальный CLI** → делаешь всё сам: ставишь скилл, собираешь доску, FULL-тир (если ollama есть), eval.
- **Cowork** → собрать доску-ПОЛ в подключённой папке можешь полностью (чистый Python). НЕ можешь: включить FULL-тир (ollama на хосте) и прописать скилл в Claude-клиент на будущее — доведи до локального запуска. Честно проговори границу.

> Заметка на будущее (бэклог «для других»): тексты этого скилла сейчас по-русски. При выходе
> на не-русскоязычных язык вывода/персон становится параметром, а не фиксированной строкой.
