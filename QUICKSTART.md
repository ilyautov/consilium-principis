# Быстрый старт

> Релиз: [v0.1.0](https://github.com/ilyautov/consilium-principis/releases/download/v0.1.0/consilium-principis.mcpb)

> Consilium даёт твоему ИИ-ассистенту **совет из персон реальных мыслителей**, грунтованных в
> их же текстах: советники обращаются к тебе, спорят между собой, дают синтез и шаг к действию.
> Это **AI-представления по текстам, а не сами люди.** Отличие от «чат-бота в роли мудреца» в
> **защитном контуре**: 🔵 цитата только дословно из корпуса, 🟡 перенос помечен, а на вопрос вне
> корпуса честный отказ, а не выдумка.

Три пути ведут к одному. Выбери по себе, **первый самый простой.**

---

## Что нужно (один раз)

| Что | Зачем | Обязательно? |
|---|---|---|
| **Python 3.10+** | пол: лексический поиск + контур (чистый stdlib) | **да** |
| **ollama + `bge-m3`** | FULL-тир: умный кросс-язычный поиск | нет, без него работает пол, контур цел |
| Аккаунты / ключи / API | не участвуют | **не нужны вообще** |

**Новая доска ПУСТАЯ, это норма.** Совет личный; кого посадить, выбираешь ты. Public-domain
мудрецы (стоики, Сунь-цзы) собираются одной фразой; современных собираешь из материалов, что принесёшь сам.

## Путь 1. Попросить Claude по ссылке (без терминала, проще всего)

1. Открой **Claude Code**.
2. Дай ссылку:
   > «Поставь мне этот навык: `https://github.com/ilyautov/consilium-principis`»
3. Claude сам склонирует и поставит (`python3 install.py` → копия в `~/.claude/skills/` →
   самопроверка `doctor`). Перезапусти Claude Code.
4. Дальше просто говори своими словами:
   - **«с чего начать»** соберёт стартовый совет (Марк Аврелий и Эпиктет) за пару минут;
   - **«что умеешь?»** покажет меню: что можно спросить, простыми фразами;
   - **«созови совет по [вопрос]»** откроет заседание.

> Cowork и другие неописанные в таблице хосты не считаются проверенными: смотри
> [`docs/CONNECT-HOSTS.md`](docs/CONNECT-HOSTS.md) и сначала проверь сгенерированный конфиг на
> своей машине. FULL-тир требует локальный Ollama и `bge-m3`.

## Путь 2. Двойной клик или одна команда

Знать код не нужно. Нужен только **Python 3.10+** (Windows: при установке с
[python.org](https://python.org) отметь «Add Python to PATH»).

1. Получи папку скилла (clone или zip), зайди в неё.
2. Запусти установщик:
   - **macOS:** двойной клик [`install.command`](install.command) (первый раз: правый клик → «Открыть»);
   - **Windows:** двойной клик [`install.bat`](install.bat);
   - **терминал:** `python3 install.py` (**Windows:** `py install.py` — см. нюанс ниже)
3. Установщик скопирует скилл в `~/.claude/skills/`, определит тир и **сам прогонит самопроверку**.
   Перезапусти Claude Code и скажи **«с чего начать»**.

> **Windows-нюанс.** Windows пока не проверен как полностью поддерживаемая платформа. python.org кладёт `py.exe` и `python.exe`, но **не** `python3.exe` (а `python3.exe`
> из Microsoft Store — заглушка, открывает магазин вместо запуска). Поэтому в терминале зови `py`, а не
> `python3`. Двойной клик `install.bat` и mcpb-бандл это уже учитывают. Если плагин в Claude Code не
> находит Python — поставь `CONSILIUM_PYTHON=py` в окружении перед запуском.

## Путь 3. Руками (для тех, кто хочет повозиться)

Из папки скилла:
```bash
python3 scripts/board.py doctor          # Python / скилл / тир / самотест контура
python3 scripts/board.py seed-council     # стартовый совет PD-мудрецов в один шаг
python3 scripts/board.py recipes          # меню «что умеет совет»
```
Свой советник в один шаг (источники → манифест тиров → валидация рва → corpus → kernels → индекс):
```bash
python3 scripts/board.py validate-manifest advisors/<имя>   # маркеры тиров реально в тексте?
python3 scripts/board.py build-advisor   advisors/<имя>     # собрать целиком
python3 scripts/eval.py advisors/<имя>                       # 🔵 verified X/X, честные отказы
```
Полный рецепт сборки советника (откуда брать источники, как писать `persona.md`, проверка каждой
цитаты контуром) лежит в [`docs/onboarding-recipe.md`](docs/onboarding-recipe.md) и [`advisors/README.md`](advisors/README.md).

## Что дальше

- **Созвать совет:** «созови совет по [вопрос]». Советники грунтуют тезисы 🔵/🟡, спорят, дают синтез и шаг.
  Считаемый вопрос-решение («что выгоднее», «стоит ли», «X или Y») переведёт совет в режим «не спорить на глаз».
- **Посчитать решение (📐):** «давай посчитаем, что выгоднее, X или Y». Совет разложит выбор на
  **карту решения** (варианты, твои числа тройками «худший/типичный/лучший», формулы) и прогонит
  детерминированный Монте-Карло: P(лучший), где рвётся, что решает исход. Считает код, не модель.
- **Не знаешь, что спросить:** «что умеешь?» покажет рецепты простыми фразами.
- **Добавить голоса или линзу:** просто скажи «добавь советника [кто]». Совет ведёт интервью (источник плюс
  «как ТЫ его читаешь») и собирает сам; руками через `board.py build-advisor`, против эхо-камеры
  `python3 scripts/diversity_check.py`.
- **Включить FULL-тир:** `python3 scripts/board.py setup-full` (подскажет про ollama, сам стянет `bge-m3`).
- **Подключить как MCP-сервер:** статус конкретного хоста в [`docs/CONNECT-HOSTS.md`](docs/CONNECT-HOSTS.md),
  подробности в [`CONNECT-MCP.md`](CONNECT-MCP.md). Из корня чекаута сначала сгенерируй конфиг:
  `python3 scripts/board.py mcp-config --json` (**Windows:** `py -3 scripts/board.py mcp-config --json`; если
  `py` нет, проверь Python 3.10+ и используй `python`, не Store-alias `python3`).
- **Контур всегда с тобой:** 🔵 слова автора (P1/P2) · 🟢 дословный комментарий (S1, с атрибуцией) ·
  🟡 перенос · 📐 расчёт (твоя модель, не цитата) · отказ вне корпуса. На любом тире поиска.
