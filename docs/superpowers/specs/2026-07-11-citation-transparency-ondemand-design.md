# Citation-Transparency On-Demand — Design Spec

**Дата:** 2026-07-11 · **Ветка:** `feat/moat-legible` (продолжаем — вся дуга «ров видимым»)
**Статус:** автономно; юзер выбрал вариант **«только по запросу»** (Rule 1 не трогаем).

## Goal

Point-of-use легибельность: ров виден **В ПРОДУКТЕ**, но **только когда юзер просит пруф** —
дефолтный вывод остаётся чистым (Rule 1 «тихая оркестрация» не нарушается). Юзер спрашивает
«покажи, что проверено / откуда это / что отклонено» → совет собирает прозрачный слой.

## Design decision (развилка решена юзером)

Из трёх вариантов (минимум-легенда / активный trust-бит / только-по-запросу) юзер выбрал
**только-по-запросу**. Значит: **дефолтное поведение НЕ меняем**, добавляем on-demand-аффорданс.

## Ключевой факт (сужает работу до INSTRUCTIONS-only)

Данные для прозрачности УЖЕ есть у хоста:
- `source` (source_ref) лежит в quote-объектах и уже рендерится (`session_render.py` показывает
  `q["source"]`; `depth=expert` добавляет англ-оригинал/пилюли).
- Разметка 🔵/🟢/🟡 в opinions уже различает «дословно проверено» vs «в духе автора».
- Воздержание = opinion пошёл 🟡 из-за отсутствия дословного — хост это знает из результата `cite`.

Значит **новый код не нужен** — нужно ДОБАВИТЬ в INSTRUCTIONS правило, которое учит хост по
запросу собрать прозрачный слой из уже полученных данных. Additive, Rule-1-safe, контур не тронут.

## Change

Расширить **Rule 7** (Подача) блоком «Прозрачность по запросу». Точный текст (вставить в конец
Rule 7, после «expert — по запросу.»):

```
   ПРОЗРАЧНОСТЬ ПО ЗАПРОСУ (ров виден, когда юзер ПРОСИТ пруф — Rule 1 при этом НЕ нарушается:
   это не «кухня» за кулисами, а осознанный запрос доказательства). Триггеры: «покажи, что
   проверено / откуда это / дай источники / что отклонено / это точно его слова?». Тогда собери
   из УЖЕ полученных данных прозрачный слой: (а) каждую 🔵-реплику — с её source_ref (издание/
   локатор, что отдавал cite), человеческим языком «проверено по <корпус автора>»; (б) где
   советник пошёл 🟡 или промолчал по НЕХВАТКЕ дословного — назови ЧЕСТНО одной строкой («у
   Аврелия дословного на это нет — не выдумываю»); это ЧАСТЬ пруфа, не оправдание. НЕ выдумывай
   источники, НЕ показывай сырьё (nonce/пути/хеши/тиры) — только человеческое «проверено по …».
```

## Out of scope

- Дефолтный вывод, Rule 1, контур — не трогаем.
- Отдельный виджет-панель прозрачности — позже (MVP = хост собирает ответ по запросу).
- Активный trust-бит по умолчанию (юзер выбрал против).
