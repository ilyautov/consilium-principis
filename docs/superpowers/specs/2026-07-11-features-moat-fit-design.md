# Moat-Fit Features — Design Spec (частично НА АПРУВ)

**Дата:** 2026-07-11 · **Ветка:** `feat/moat-legible`
**Статус:** дизайн. Низкориск-часть строю; поведенческую (INSTRUCTIONS/новые тулы) — НА АПРУВ.

## Реальность (исследование кода перед дизайном — сузило скоуп)

«Именованные режимы» из research-списка **УЖЕ ЕСТЬ** как рецепты (`recipes.json`, тул `list_recipes`):
`full-council` (Expert Panel), `ask-one`, `clash-two` (столкнуть два взгляда), `premortem`,
`argument-engine` (выиграть спор), `mirror`, `close-outcome`, `calibrate`, `start`, `add-advisor`.
→ **Не рестроим.** Пробел не «нет режимов», а несколько конкретных незакрытых углов.

## Реальные пробелы (приоритизированы)

### A. Executive brief — фикс-делеверабл «риски / возможности / шаг» (низкий риск — СТРОЮ)
Новый рецепт `exec-brief` в `recipes.json` (data-level, паттерн существующих рецептов): совет по
решению выдаёт компактный executive-формат — 3 блока (ключевые риски / возможности / рекомендованный
шаг), поверх уже существующей машинерии заседания. Ноль правок контура, ноль новых тулов — рецепт
направляет хост. Гард: тест, что рецепт присутствует и валиден (как остальные).

### B. Red-team / «адвокат дьявола» — именованный рецепт (низкий риск — СТРОЮ)
Рецепт `red-team`: «разнеси мой план» — совет намеренно атакует замысел юзера ПО СУЩЕСТВУ (не
фабрикуя; лейблы моата действуют). Отличается от `argument-engine` (там юзер выигрывает ЧУЖОЙ спор) —
здесь совет оппонирует ЮЗЕРУ. Data-level рецепт.

### C. Session share / «пруф-кард» (СРЕДНИЙ — НА АПРУВ)
Экспорт заседания в шеримый артефакт (md/html), несущий наш дифференциатор: 🔵-цитаты с источником +
что было воздержано. Вирусная петля (research: дистрибуция=формат первого контакта) + витрина рва.
Требует нового тула `export_session(session)` → отдаёт самодостаточный html/md. **Приватность:**
экспорт ТОЛЬКО по явному запросу юзера, ТОЛЬКО текущее заседание, public-domain примеры; реальные
council/-данные не автоэкспортируются. Дизайн-развилка на апрув (формат, где хранится, редакция PII).

### D. Daily ritual — verbatim-цитата дня (СРЕДНИЙ — НА АПРУВ)
Ретеншн-крючок: по запросу/ритуалу — одна 🔵 verbatim-цитата дня из PD-корпуса собранных советников
(честная, с источником — не generic-мудрость). Требует лёгкого тула `quote_of_day(advisor_dir?)`
поверх cite. Развилка: пуш vs pull (мы НЕ хотим навязчивости — только pull, по запросу). На апрув.

## Что строю сейчас (низкий риск, data-level)
A (exec-brief) + B (red-team) — записи в `recipes.json` + гард-тест их наличия/валидности. Ноль
правок INSTRUCTIONS/контура/тулов. C и D — держим как спеку до твоего слова (новые тулы + приватность).

## Testing
- Гард в существующем тесте рецептов (или новый `test_recipes_moat_fit.py`): `exec-brief` и `red-team`
  присутствуют, имеют обязательные поля (id/title/…) как остальные рецепты, `list_recipes` их отдаёт.
- Полный офлайн-сьют зелёный; selfdoc-regen если новый тест-файл.

## Out of scope
- Голос/аудио, компаньон-фичи (off-moat).
- Рестрой существующих 10 рецептов.
- C/D реализация — до апрува.
