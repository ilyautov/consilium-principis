## Ядро

Листинг в каталоге НЕ приносит трафик сам по себе (реестр unopinionated, не ранжирует качество).
Дистрибуция = отдельная работа поверх листинга. Отстройка идёт НЕ через «AI-council» (мёртвая
позиция при 5+ конкурентах), а через outcome, которого у соперников нет: **provenance / verbatim /
fail-closed** — «докажет цитату или откажется отвечать».

## Рычаг 1. Дистрибуция по MCP-каталогам (чек-лист)

Официальный **MCP Registry** (`registry.modelcontextprotocol.io`, статус preview, схема server.json
2025-12-11):

1. Опубликовать пакет в package-реестр СНАЧАЛА (реестр хранит только метаданные, не артефакт).
   Для Python-проекта это PyPI; либо npm-обёртка. ⚠ у нас пакет сейчас ставится через git/plugin —
   надо решить формат пакета (PyPI vs npm-shim) до подачи.
2. `mcp-publisher init` → `login` → `publish` (CLI).
3. Namespace = **`io.github.ilyautov/consilium-principis`** (GitHub OAuth-аутентификация владения).
   `mcpName` в package.json ОБЯЗАН совпадать с `name` в server.json, иначе permission-error.
4. Кастомный домен (com.brand reverse-DNS) не нужен на старте — GitHub-namespace достаточно.

**Фрагментация (опровергнут миф «одна запись пропагируется во все»):**
- PulseMCP и семейство авто-ингестят из официального реестра → подхватят автоматически.
- **Smithery, Glama, MCP.so, Raycast, FluidMCP** — параллельные реестры, требуют ОТДЕЛЬНОЙ ручной
  подачи. → чек-лист: (1) официальный реестр, потом (2) руками в Smithery + Glama + MCP.so.
- Claude Code plugin marketplace у нас уже есть (`/plugin marketplace add ilyautov/consilium-principis`).

## Рычаг 2. Show HN (что подтверждено, что опровергнуто)

Подтверждено (качественные принципы):
- Заголовок **кристально ясный про то, ЧТО делает**, БЕЗ суперлативов (fastest/first/best —
  «скромный язык сильнее»).
- Лидировать **open-source / privacy-first** углом (HN over-index на это) — у нас правда (MIT,
  локальный контур, приватный корпус).
- **Убрать все барьеры к пробе**; ссылка на GitHub-репо = сигнал «это рабочий продукт».
- Кандидат-заголовок: *«Show HN: Consilium — open-source AI council that cites verbatim or refuses to answer»*.

Опровергнуто (0-3, НЕ использовать как факт): конкретный оптимальный день/час (Tue-Thu 9-12 ET),
формат заголовка «+40%», пороги launch-day (30-50 апвотов за час, ответ <15 мин). Это народная
мудрость, не эмпирика.

## Рычаг 3. Demo-as-distribution (демо как код)

- Строить терминальное демо **декларативно через VHS** (charmbracelet): один `.tape` → GIF (README),
  MP4/WebM (X/TikTok), PNG-фреймы (thumbnails). Воспроизводимо, версионируется в git.
  Альтернатива: `asciinema rec` → `agg` (GIF) или `svg-term-cli` (self-contained SVG без JS-плеера).
- **GIF < 10 сек** (иначе теряется внимание, раздувается размер).
- Сценарий демо (наш): 8-10 сек, «запрос → 🔵 дословная цитата с источником ИЛИ честный отказ».
  Демо в README резко поднимает первое впечатление (видно как работает без чтения README/клона).

## Рычаг 4. Первые 100 юзеров

- **Один канал ВГЛУБЬ, не 5+ вширь** («тонкое присутствие везде / сильное нигде»). Мульти-канал —
  награда за дисциплину, не старт. Освоить основной, добавлять по одному.
- Выбрать ОДИН: HN ИЛИ r/ClaudeAI ИЛИ MCP-каталоги — и вложиться. (Карта конкретных площадок под
  нашу нишу НЕ верифицирована — см. пробелы.)

## Рычаг 5. Позиционирование заголовка

- «AI-powered X» / «AI council» перестаёт быть позицией при 5 конкурентах. Якорь = чего у соперников
  НЕТ (provenance/verbatim/fail-closed).
- Заголовок **мнённый** (притягивает одних, отталкивает других — это цель); generic-прилагательные
  (trustworthy/accurate/enterprise-ready) проваливаются («все кивают, никто не отличает»).
- **Refusal-фрейм** — рекомендуемая тактика: заявлять, что ты ОТКАЗЫВАЕШЬСЯ делать. Прямо ложится на
  fail-closed «откажется блефовать». First Round использует Anthropic/Claude как флагманский пример
  этой тактики.
