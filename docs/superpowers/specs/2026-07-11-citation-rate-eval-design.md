# Citation-Rate Eval (ALCE-style) — Design Spec

**Дата:** 2026-07-11 · **Ветка:** `feat/moat-legible` · **Статус:** дизайн (experiment-first, как [[Tier1]]/анти-сикофантика).

## Goal

Превратить строгость в **публикуемое число**: измерить, какая доля наших цитат ДОСЛОВНО проверена
против PD-корпуса, и сопоставить с baseline «голый LLM выдумывает». Дать лончу цитируемый факт вида
«у нас X% реплик-цитат сверены посимвольно и несут источник; вне корпуса совет воздерживается, а не
галлюцинирует» — вместо голого маркетинга.

## Метрики (ALCE-адаптация)

На множестве вопросов, прогнанных через совет:
- **Citation precision:** доля 🔵-помеченных цитат, которые РЕАЛЬНО проходят наш verbatim-гейт
  (посимвольно есть в корпусе). Цель = 1.0 (гейт fail-closed — не должен пропускать невернифиц.).
- **Abstention correctness:** на вопросах ВНЕ корпуса — доля, где совет воздержался (🟡/молчание),
  а НЕ выдал 🔵. Мера честного молчания.
- **Baseline-контраст:** тот же вопрос голому LLM (без нашего контура) → доля «цитат», которые НЕ
  находятся дословно ни в одном источнике (= фабрикация). Это и есть «~50% неподкреплённых» из ALCE-лит.

## Подход: изолированный офлайн-каркас + живой прогон (как Tier1)

`scripts/experiments/citation_rate_eval.py` — рантайм НЕ импортирует. Переиспользует verbatim-гейт
(`fidelity_check`/протокол-гейт — он уже ДЕТЕРМИНИРОВАННЫЙ Python, офлайн). Статистика — bootstrap-CI
из `antisycophancy_probe` (DRY).

- **Офлайн (строится без ключа):** батарея вопросов (в-корпусе + near-miss вне-корпуса) + FIXTURE
  council-ответы (детерминированные) → прогон через настоящий гейт → метрики precision/abstention.
  Проверяет машинерию eval end-to-end. Тест на mock-фикстурах.
- **Живой (нужен ключ):** реальные council-ответы (наш контур) vs голый LLM baseline через
  `llm_local`/OpenRouter → реальные числа для публикации. `--run`, fail-closed без ключа.

**Ключевой момент честности:** citation precision меряется НАШИМ ЖЕ гейтом — это не «доказательство
рва третьей стороной», а проверка ВНУТРЕННЕЙ консистентности (гейт не пропускает невериф.). Для
внешне-валидного числа baseline-контраст (фабрикация голого LLM) важнее — его считаем тем же гейтом
на выходе голого LLM. Оговорка идёт в README рядом с числом.

## Testing
- Офлайн-тест: fixture-ответы (часть с настоящими 🔵-цитатами из корпуса, часть с подделками) →
  precision корректно = (настоящие)/(настоящие+подделки), abstention корректно на вне-корпусных.
- Детерминизм (fixed SEED), полный офлайн-сьют зелёный, selfdoc-regen если новый тест-файл.

## Решение по исходу
Живое число сильное (высокий precision + явный контраст с baseline) → **публикуем в README/лонче** с
честной оговоркой про «меряно нашим гейтом». Слабое/шумное → не публикуем, но каркас остаётся.

## Out of scope
- Внешний бенчмарк-датасет (ALCE-корпус) целиком — берём наш PD-корпус + сконструированную батарею.
- Интеграция метрики в рантайм — это оффлайн-инструмент оценки, не продакшн-фича.

Строится идентично Tier1 (тот же паттерн probe) → быстрый, если апрувишь. Связано: [[council-topology-northstar]].
