# scripts/experiments/ — архив разведочных прогонов

История исследований ретрива/провенанса. Это **не продакшн-код**: ни один прод-путь
и ни один тест их не импортирует. Держим их ради **воспроизводимости замеров** —
каждый из этих прогонов проверял гипотезу улучшения и вернул ноль, и это доказательство
живёт здесь, а не удалено.

| Скрипт | Что мерил | Исход |
|---|---|---|
| `exp_bridge.py` | ретрив-мост между языками/доменами | ноль (мост = театр, McNemar c=0) |
| `exp_graph.py` | граф-провенанс как сигнал ретрива | не дал выигрыша |
| `exp_kernels.py` | извлечение «ядер» идей советника | ядро вынесено в прод `corpusbuild.kernel_extract`; сам прогон — разведка |
| `exp_kernels_finer.py` | более тонкая нарезка ядер | без выигрыша |
| `diagnose_retrieval.py` | диагностика тиров ретрива | инструмент замера |
| `diagnose_multiquery.py` | Левер 2: перефразировки → RRF (`engine.multi_query`) | ноль на RU (пятый ноль; дешёвые рычаги исчерпаны) |

## Как запускать

Из корня репозитория (пути к `corpusbuild`/`engine`/`eval` они добавляют сами через
`sys.path`, указывающий на родительский `scripts/`):

```bash
python3 scripts/experiments/diagnose_retrieval.py
```

Некоторым нужны живой корпус (`build/…`), сеть (OpenRouter/ollama) или собранные
эмбеддинги — это разведочные прогоны, не самодостаточные тесты.
