# Генеративный мост P1 — провенанс-граф, калибровка, валидация — Design

> Статус: DESIGN (2026-06-25). Реализация стадий 5-7 corpus-builder'а ([[corpus-builder-design]] §8)
> и Layer 2 ([[provenance-corpus-schema]] §L2). P0 (tier-aware корпус) закрыт — это надстройка.
> Объём согласован с юзером: ПОЛНЫЙ P1 сразу (линки + энричмент + kernel-граф), затем Exp A.

## 0. Зачем

Тиры решают «чьи это слова». P1 решает «как советник ДУМАЕТ» и «как дотянуть русский запрос до
англоязычного первоисточника, не сломав ров». Три производителя рёбер строят ОДИН граф провенанса;
маркер ответа (🔵/🟢/🟡) считывается автоматически как **самое слабое звено на трассе** (L2.2).

## 1. Архитектура: один граф, версионируемые артефакты

Поверх tier-aware `build/corpus.jsonl`. Узлы: `кернел` · `P1-пассаж`(🔵) · `S1-толкование`(🟢) ·
`enrichment`(пример/ситуация/кросс-домен, derived) · `ситуация юзера`. Рёбра пишутся 3 модулями,
собираются 4-м. Всё в `build/` (gitignored).

```
build/
  links.jsonl       {src: tarasov_chunk_id, dst: p1_chunk_id, type:"толкует", weight: cos, cross_lingual:true}
  kernels.json      [{name, method, grounded_in:[p1_chunk_id…], validated:bool, val_score:float}]
  enrichment.jsonl  {id, kind, derived_from:[p1_chunk_id…], tier:"derived", never_quote:true, text, traces_to_kernel?}
  graph.jsonl       {src_id, dst_id, type, weight}     # унификация links+grounding+enrichment
  bridge.lock.json  {built_at, embed_model, counts, source_hashes}   # воспроизводимость (как build.lock)
```

`chunk_id` = детерминированный `f"{source}:{start}-{end}"` из corpus.jsonl (start/end теперь верны
после фикса overlap-провенанса).

## 2. Пререкизит P0.5 — чистка front-matter Макиавелли

Манифест Макиавелли сейчас БЕЗ регионов → интро переводчиков (Marriott: стр. 1-519 `INTRODUCTION`,
`THE MAN AND HIS WORKS`; Thomson: аналогично) помечено P1. Подтверждено образцом: *«The little book
suffered many vicissitudes… Although Machiavelli discusses…»* — слова Marriott, не Макиавелли. Без
чистки кернелы заземляются в текст переводчика, а P1-якоря Exp A грязные.

**Действие:** добавить `regions` в манифест (интро→B, тело→P1, хвост-notes→S1) ровно как для Аврелия;
маркеры: Prince — B until `DEDICATION`, P1 from `DEDICATION`; Thomson — аналогично по его структуре.
Точные строки верифицируются против region-preview доктора (§5). Пересобрать оба советника.

## 3. Компоненты (новые модули `corpusbuild/`, каждый — одна ответственность, TDD)

### 3.1 `link.py` — S1→P1 кросс-язычный семантический мост
Эмбеддим P1- и S1-чанки (bge-m3 через хелпер `exp_kernels.embed`, многоязычный → русский Тарасов
матчится к английскому Prince). Для каждого Тарасов-чанка top-m P1-пассажей по косинусу, порог
`min_cos` (отсечь мусорные линки) → `links.jsonl`. Это сам мост. Интерфейс: `build_links(advisor_dir,
top_m=3, min_cos=0.45) → [link…]`. Где P1-матча выше порога нет — линка нет (честно: чанк — своя идея
комментатора, останется 🟢 без моста к автору).

### 3.2 `kernels.py` — извлечь + заземлить кернелы
Переиспользуем уже фальсиф-валидную экстракцию (`exp_kernels.extract_kernels`, [[meta-ideas-validated]]).
Каждый кернел ЗАЗЕМЛЯЕМ: top-N ближайших P1-пассажей (bge-m3) → `grounded_in`. `validated`/`val_score`
из held-out-дискриминации (L2.4). **L2.3.1: безземельный кернел (нет ≥N P1-пассажей выше порога) не
существует — выкидываем.** Интерфейс: `build_kernels(advisor_dir, k=6, ground_n=5) → kernels.json`.

### 3.3 `enrich.py` — калиброванная LLM-расшифровка
Для P1-пассажей (или сгруппированных по кернелу) LLM генерит `kind ∈ {пример, ситуация,
кросс-домен, осовременивание}`, `derived+never_quote`, `derived_from`=исходные p1_chunk_id →
`enrichment.jsonl`. **L2.3.2: кросс-домен ВСЕГДА 🟡 и обязан нести `traces_to_kernel`** (поводок).
Интерфейс: `build_enrichment(advisor_dir, kinds=[…]) → enrichment.jsonl`.

### 3.4 `graph.py` — сборка + правило слабого звена
Унифицирует links+grounding+enrichment в `graph.jsonl`. Ключевая чистая функция
`weakest_link(path: list[node]) → marker`: путь только по 🔵 → 🔵; прошёл 🟢 → 🟢; дотянулся
экстраполяцией (enrichment/кросс-домен/ситуация юзера) → 🟡. Это L2.2-правило, ядро контура на графе.

### 3.5 fidelity-интеграция
`fidelity` получает `marker_for_path(path, advisor_dir)` — оборачивает `graph.weakest_link`. Ответ,
собранный по трассе, маркируется слабейшим звеном. Не ломает существующий `is_blue_eligible`
(вербатим-гейт остаётся как нижний слой для 🔵).

## 4. Калибровка — три правила (L2.3), проверяются доктором
1. **Нет безземельных кернелов** — каждый ≥N 🔵-пассажей, иначе не существует (§3.2).
2. **Кросс-домен всегда 🟡** и трассируется к кернелу (§3.3).
3. **Граф эвалится** — рёбра LLM не выдуманы (§6.2).

Доктор (§5) расширяется инвариантами: нет `derived`/`S1` в 🔵-пуле; нет безземельных кернелов;
каждый кросс-домен-enrichment имеет `traces_to_kernel`.

## 5. Доктор-гейт расширение
`doctor.report` дополнительно: число линков/кернелов/enrichment; **region-preview** (первые/последние
2 строки каждого региона на сборку — глазами видно, верна ли граница, риск §9 corpus-design);
3 калибровочных инварианта (§4). Валит на нарушении.

## 6. Валидация — две, обе ФАЛЬСИФИЦИРУЕМЫЕ

### 6.1 Эксперимент A — мост даёт recall (гибрид)
`scripts/exp_bridge.py`. Вопрос: добавляет ли русский Тарасов-мост recall P1-якорей над текущим
базлайном translate-query?

- **Powered-набор (back-translation):** сэмпл held-out P1-пассажей (после P0.5-чистки → реальный
  Макиавелли). LLM пишет русский ситуационный вопрос, ответ на который = пассаж. Gold = этот пассаж
  (известен по построению, НЕЗАВИСИМ от моста → не круговой). N≥100.
- **Sanity-набор (Тарасов-домен):** ~15 русских современных бизнес-ситуаций (фрейм Тарасова), gold —
  применимый принцип, размечен отдельным судьёй. Качественная экологичность, не для статистики.

Условия:
- **B0** наивный: русский запрос → прямой ретрив P1 (bge-m3 многоязычный, без перевода).
- **B1** translate-query (текущий продакшн-фикс [[retrieval-translate-query-not-corpus]]): RU→EN→P1.
- **T** мост: RU-запрос → ретрив Тарасов-S1 → по `links.jsonl` → P1-якоря.
- **T+B1** объединение/реранк.

Метрика: recall@k (k=1,5,10) gold-пассажа. **Headline: T+B1 vs B1 и T vs B1**, значимость McNemar
(парные запросы) или bootstrap-CI. **Фальсификация: если T+B1 ≤ B1 — мост театр, не строим дальше
энричмент-генерацию на нём.** Печатаем k, что отсечено, без молчаливых капов.

### 6.2 Граф-валидация (L2.3.3) — рёбра не галлюцинированы
`scripts/exp_graph.py`. Рёбра, что построил LLM (enrichment `derived_from`, кросс-домен
`traces_to_kernel`), проверяем held-out-предсказанием: узлы заземлены, связь предсказывает отложенный
пассаж лучше случайной (как kernel-валидация, но для рёбер). Биномиальный/перестановочный тест.

## 7. Тестирование
Каждый модуль TDD на синтетике: `link` (косинус-порог, кросс-линк), `kernels` (заземление, выброс
безземельных), `enrich` (derived+never_quote, trace), `graph` (`weakest_link` на путях всех маркеров).
`exp_bridge`/`exp_graph` — отдельные скрипты со статтестами (не юнит-гейт, а исследования).
Доктор-инварианты — юнит-тесты.

## 8. Приватность (жёстко, неизменно)
Тарасов — личная легальная копия, **не редистрибутируется**. `links.jsonl`/`enrichment.jsonl` могут
содержать куски Тарасова дословно → весь `build/` gitignored (уже так). Enrichment — `derived`, не 🔵,
trace к источнику. Кернелы/граф — машинерия, но если несут вербатим Тарасова — остаются gitignored.

## 9. Порядок сборки (в план)
P0.5 (регионы Макиавелли) → `link` → `kernels` → `enrich` → `graph` → fidelity-интеграция →
доктор-расширение → Exp A → граф-валидация. Каждый модуль самостоятелен и тестируем; кульминация —
две фальсифицируемые валидации.
