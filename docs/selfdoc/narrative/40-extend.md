# Как расширять проект

**Добавить тул MCP.** Новая запись в словаре `TOOLS` в `scripts/mcp_server.py`:
`{description, input_schema: _obj({...поля...}, [обязательные]), handler}`.
Этого недостаточно — тул нужно ПРОВЕСТИ хосту: либо упомянуть в
`INSTRUCTIONS` (правила поведения), либо в `recipes.json` (меню «что
умеет совет»), либо явно занести в реестр внутренних тулов в
`docs/dev/internal-tools.md`, если он plumbing/maintenance-only. Иначе
регрессионный гард `tests/test_no_dark_tools.py` покраснеет — он проверяет,
что «ноль тёмных тулов»: каждый зарегистрированный тул либо виден хосту
(через INSTRUCTIONS/описание тула-родителя/рецепт), либо явно объяснён как
внутренний. Плюс — обычный TDD-тест на сам хендлер тула.

**Добавить советника или линзу.** Два пути, оба начинаются с public-domain
для публичного дистрибутива (см. файл про firewall — приватные советники
живут только локально в `advisors/*` и никогда не коммитятся):
- `catalog_add` — взять из PD-каталога или по URL; автоматически стрипает
  редакторский аппарат книги и сверяет подпись/происхождение при сборке.
- `build_advisor` — ручная сборка: положить источники в `sources/`, описать
  тир-манифест (`sources/manifest.json`, какие регионы — слова автора P1/P2,
  какие — комментарий S1/S2, какие — аппарат A/B), провалидировать манифест
  (`validate_manifest` — региональные маркеры обязаны дословно быть в
  тексте, иначе тиры съедут), затем прогнать сборку в один шаг.

Только public-domain материалы годятся для публичного скилла; копирайтные и
приватные источники остаются на локальной доске пользователя.

**После любых изменений кода.** Индекс само-документации нужно пересобрать:
```
python scripts/gen_selfdoc.py
```
Это регенерирует `docs/selfdoc/index.json` (churny факты: тулы, правила,
рецепты, скрипты). Если код изменился, а индекс не пересобран,
`tests/test_selfdoc_fresh.py` покраснеет — он сверяет индекс с текущим
состоянием репозитория и ловит рассинхрон. Нарративные файлы в этой папке
(медленно меняющееся «почему») в индекс не входят и пересборкой не
затрагиваются — их правит человек руками, когда меняется сама суть
архитектуры, а не список тулов.
