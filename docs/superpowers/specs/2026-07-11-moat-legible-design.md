# Moat Legible + Honest Offline — Design Spec

**Дата:** 2026-07-11
**Ветка:** `feat/moat-legible`
**Статус:** автономный прогон (юзер спит, делегировал «от спеки до тестов»). Решения приняты
контроллером единолично; **пункты, помеченные ⚠ REVIEW — вкусовые/позиционные, пройтись утром на догфуде.**

## Goal

Опция 1 из стратегической развилки: **сделать ров видимым (legible)** + **убрать собственный
оверклейм «работает офлайн»**. Ров = заземлённость + проверяемая цитата + fail-closed. Он у нас
уже РАБОТАЕТ, но (а) не вынесен на витрину как заголовочный пруф (урок Delphi/ALCE), (б) подорван
нашим же неточным «offline»-клеймом, что бьёт по строгости, которой мы отстраиваемся от инфоцыган.

## Что уже есть (и потому НЕ трогаем)

Исследование кодовой базы перед дизайном показало — большая часть «фич» опции 1 уже в коде:

- **Формат «где сходятся / где клэшат / след. шаг»** — уже в контракте рендера, Rule 3(в):
  `synthesis {question, reframe?, advisors, disagreement?, synthesis, step}`. `disagreement?` = клэш,
  `synthesis` = схождение, `step` = шаг. **Поведенчески добавлять нечего.**
- **Citation rendering** — 🔵 + source уже рендерятся (Rules 5, 7).
- **Оверклейм «offline» отсутствует в INSTRUCTIONS** (grep по `mcp_server.py` — ноль совпадений
  `offline/без ключей`). Живёт ТОЛЬКО в README.

**Вывод (⚠ ключевое унилатеральное решение):** скоуп опции 1 = **README/позиционирование +
регресс-гард**. INSTRUCTIONS / контур / поведение сервера **не трогаем**. Обоснование: правка
поведенческих INSTRUCTIONS пока юзер спит — выше-регретна и не нужна (клэш-формат и цитаты уже есть).
Легибельность — задача витрины (README), не поведения.

## Scope (что делаем)

### 1. Честная переформулировка «offline» (корректность, НЕ вкусовое)

Точные места (остальные упоминания офлайн уже корректно заужены на «контур»/«честность» —
строки 76, 143 — их НЕ трогаем):

- **README:15 (бейдж)** `![Works offline · no keys]` → заменить на честный.
  **Решение:** `![no extra keys · no extra cost](https://img.shields.io/badge/no%20extra%20keys%20%C2%B7%20no%20extra%20cost-success)`.
  Правда: навык не добавляет своих ключей и оплаты — едет на хосте, который юзер уже оплачивает.
  Слово «offline» из бейджа убираем (вводит в заблуждение: рассуждение советников облачное).
- **README:32** (в блоке «Что это», сейчас uncommitted) последнее предложение
  `Работает офлайн, без ключей и оплаты.` →
  `Не требует своих ключей и оплаты — работает на агенте, который у тебя уже есть; сам контур
  честности не нуждается в сети. Полный офлайн — только на локальных моделях.`

### 2. Citation-transparency на витрину (⚠ REVIEW — позиционное)

Ров легибелен, когда пруф виден СРАЗУ. Действия в README, БЕЗ переписывания авторского голоса:

- В героя (после существующего слогана, строки 7-11) добавить одну **проверяемую** строку-пруф в
  духе Delphi/ALCE: *«Каждая 🔵-цитата сверена с подлинным текстом автора посимвольно; чего в
  корпусе нет — советник не произносит. Это можно проверить, а не поверить на слово.»*
- Секцию «Почему этому можно верить» (строки 64-76) переупорядочить так, чтобы **citation-proof
  шёл первым** (сейчас он в таблице ниже анти-лести). Таблицу маркеров сохранить как есть.

### 3. Боль-хук (⚠ REVIEW — вкусовое, ЛЁГКИЙ драфт, НЕ финал)

Урок Ole Lehmann: вести болью, не механикой. **Решение:** НЕ переписываю авторский слоган. Добавляю
ОДНУ опциональную строку-боль как **HTML-комментарий-предложение** в README рядом с героем
(`<!-- ⚠ вариант боль-хука на утро: "..." -->`), чтобы юзер выбрал голос сам. Контроллер копирайт
не финалит.

### 4. Регресс-гард (корректность)

`tests/test_readme_honest_claims.py` — фиксирует, что оверклейм не вернётся:

- README НЕ содержит неквалифицированной подстроки `Работает офлайн, без ключей` (whole-product claim).
- Бейдж НЕ содержит `works-offline` / `Works offline`.
- Каждое упоминание слова `офлайн`/`offline` в README (кроме бейджа-ссылки) стоит рядом (в том же
  абзаце/строке) с квалификатором из набора: `контур`, `локальн`, `агент, который у тебя уже есть`.

**Примечание по selfdoc:** новый тест-файл, вероятно, сдвинет `test_selfdoc_fresh` (индекс считает
тест-файлы) — тогда регенерировать `scripts/gen_selfdoc.py` → `scripts/build_manual.py` и внести
`docs/selfdoc/index.json` + `docs/MANUAL.md` в тот же коммит (известный паттерн, случалось дважды).
Если гард живёт БЕЗ сдвига (проверить прогоном) — regen не нужен.

## Out of scope (явно)

- Любые правки INSTRUCTIONS / контура / поведения сервера.
- Мемные триггеры («council this»), кросс-хост-дистрибуция, агрегаторы — отдельная работа
  (дистрибуция), не эта опция.
- Northstar-федерация (две оси × best-of-N) — зафиксирована в память, НЕ строится.
- Виджет-легенда «что значит 🔵» для не-тех юзера — след. работа (UI), не README.

## Testing

- Новый гард `tests/test_readme_honest_claims.py` — прогон в офлайн-инварианте:
  `HEPHAESTUS_ENGINE=/nonexistent OLLAMA_HOST=http://127.0.0.1:59999 python3 -m pytest tests/test_readme_honest_claims.py -q`.
- Полный офлайн-сьют зелёный перед финалом (env-flaky `test_ssrf_check_passes_public_blocks_private`
  игнорируем — известный).

## Constraints

- Ветка `feat/moat-legible`, **без push/merge** — ждёт firewall-ритуал + догфуд юзера.
- Только public-domain примеры в README (уже так).
- Не ослаблять fail-closed (мы его вообще не трогаем — только точнее ОПИСЫВАЕМ).
