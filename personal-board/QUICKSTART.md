# Быстрый старт — соберите свой совет директоров

> personal-board (Consilium) даёт вашему ИИ-ассистенту **совет из персон реальных
> мыслителей**, грунтованных в их же текстах: советники обращаются к вам, спорят между
> собой, дают синтез и шаг к действию. Отличие от «чат-бота в роли мудреца» — **защитный
> контур**: цитата 🔵 только дословно из корпуса, перенос помечается 🟡, на вопрос вне
> корпуса — честный отказ, а не выдумка.

Три пути ниже ведут к одному результату. Выберите по себе.

---

## Сначала — что нужно (один раз)

| Что | Зачем | Обязательно? |
|---|---|---|
| **Python 3.10+** | пол: лексический ретрив + контур (чистый stdlib) | да |
| **ollama + `bge-m3`** | FULL-тир: семантический ретрив (точнее на большом корпусе) | нет — без него работает пол, контур цел |
| Аккаунты / ключи / API | — | **не нужны вообще** |

**Из коробки доска ПУСТАЯ — и это норма.** Совет — ваш личный, кого посадить выбираете вы.
Советников вы собираете сами (Путь 1 проведёт за руку). Легальная граница: тексты
public-domain тянутся свободно; копирайтные книги — только ваши **легальные копии** в
`advisors/<имя>/sources/` (эта папка не уходит в репозиторий).

---

## Путь 1. Самый простой — попросите своего ИИ (без терминала)

Для тех, кто не хочет видеть командную строку.

1. Откройте **Claude Code**, **Claude Desktop** или **Cowork**.
2. Скажите ассистенту дословно:
   > «Собери мне доску советников.»  (или: «Добавь советника — Марк Аврелий.»)
3. Дальше следуйте подсказкам: ассистент откроет навык установки
   (`install-skill/`, см. папку), определит тир, **соберёт первого советника** (найдёт
   PD-источник → построит корпус → напишет профиль → проверит каждую цитату контуром) и
   покажет проверку. Вы только называете, кого хотите.

> Почему ИИ не делает всё молча в Cowork: песочница — изолированный Linux-контейнер. Но
> наш **пол это чистый Python**, поэтому рабочую доску ассистент может собрать прямо в
> подключённой папке. Для FULL-тира (ollama) и установки скилла на будущее — доведёт вас
> до локального запуска. Навык честно проговаривает границу.

## Путь 2. Получить папку и запустить (рекомендуется большинству)

Не нужно ничего знать про код. Нужен только **Python 3.10+**
(Windows: при установке с [python.org](https://python.org) отметьте «Add Python to PATH»).

1. Получите папку скилла (clone / zip / подключите в Cowork). Перейдите в неё.
2. **Определите тир** (из папки скилла):
   ```bash
   python3 -c "import sys; sys.path.insert(0,'scripts'); from engine.semantic import SemanticEngine; print('semantic:', SemanticEngine.available())"
   python3 scripts/board_init.py advisors --semantic-available true   # или false, если semantic: False
   ```
3. **Соберите первого советника** — проще всего попросить ИИ («добавь советника — …»),
   либо пройти рецепт руками (collect → build → persona → проверка цитат → eval).
   Полностью — в `install-skill/SKILL.md`, Шаг 3.
4. **Проверьте:**
   ```bash
   python3 scripts/doctor.py                 # активный тир + что контур работает
   python3 scripts/eval.py advisors/<имя>     # 🔵 verified X/X, честные отказы
   ```

> 🖱 Клик-установщик (`install.command`/`.bat`/`.sh`) — в работе. Пока самый чистый путь —
> Путь 1 (попросить ИИ) или эти команды.

## Путь 3. Руками (для тех, кто хочет повозиться)

Полный рецепт по шагам — сбор источника, `build_advisor`, написание `persona.md`,
**проверка каждой цитаты через `verbatim_in_corpus`**, `board_init`, `tier_full` (для FULL),
golden-набор и `eval` — расписан в `install-skill/SKILL.md` (Шаг 3) и `advisors/README.md`.

## Что дальше

- **Созвать совет:** «созови совет по [вопрос]» — советники грунтуют тезисы 🔵/🟡, спорят, дают синтез и шаг к действию.
- **Добавить голосов:** повторите сборку; `python3 scripts/diversity_check.py` — против эхо-камеры.
- **Включить FULL-тир позже:** `ollama pull bge-m3`, живой ollama на `:11434`, затем перезапустите Шаг 2.
- **Контур всегда с вами:** 🔵 = дословная цитата, 🟡 = перенос, отказ = вне корпуса. На любом тире.
