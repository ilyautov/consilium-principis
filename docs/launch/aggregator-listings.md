## Long description (~150 words)

Every AI "council of advisors" tells the same story: several models deliberate, peer-review each other, and hand you a synthesis with a confidence score. None of them show you whether the quotes are real.

Consilium Principis is different. It's a Claude Code skill and MCP server that convenes a council of AI personas of real thinkers — Sun Tzu, Marcus Aurelius, Machiavelli, Epictetus, plus advisors you build from your own legally held sources — grounded in their public-domain texts. Every verbatim quote a council member cites is checked character-by-character against the actual source corpus before it reaches you: verified quotes are marked 🔵, and when the corpus doesn't cover your question, the advisor honestly says so instead of fabricating an answer (fail-closed, not fail-plausible).

Lenses genuinely disagree instead of converging into one mushy consensus, and quantifiable decisions get a deterministic Monte Carlo simulation (📐). Runs on the Claude Code agent you already have — no extra API keys, no added cost, sessions stay local. Free, open source, MIT licensed.
