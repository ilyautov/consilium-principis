# Функциональные линзы (бизнес-функции как советники)

Это **не персоны реальных людей**, а методы дисциплин: Стратег, Финансист (CFO), Маркетолог,
Продажник. Каждая линза = набор кернелов (фреймворков функции) без одного автора.

## Чем отличаются от persona-советников
| | persona-советник (Макиавелли) | функциональная линза (CFO) |
|---|---|---|
| грунт | корпус реальных слов автора | **нет корпуса** — только кернелы дисциплины |
| маркеры | 🔵 (P1/P2) / 🟢 (S1) / 🟡 | **только 🟡** (метод) — 🔵 невозможен by-design |
| где живёт | `advisors/` (приватно, gitignored, легальная граница) | `lenses/` (генерик, часть скилла, коммитим) |

**Почему 🔵 невозможен:** у линзы нет `corpus.jsonl` → tier-aware гейт (`fidelity.fidelity_check`)
не находит P1/P2-матч → максимум 🟡. Честность гарантируется структурно, не на доверии.

## Зачем
Патчат **доказанное слепое пятно** совета (A/B 2026-06-23): философские линзы проскакивают
практичное. CFO спросит «на что это влияет в деньгах», продажник — «кто реально это купит» —
углы, которых Макиавелли с Аврелием не трогают. Ортогональная ось к `diversity_check`.

## Грейды честности

- **grounded** (v0.2): добавить канон-корпус функции (Огилви, Котлер…) → 🔵 с именем автора.

Добавить линзу = новый `.md` с frontmatter (`grade: frame-lens`, `marker_ceiling: 🟡`) + `## Кернелы`.
