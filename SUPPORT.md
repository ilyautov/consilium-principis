# Support

For installation, configuration, and usage questions, open a GitHub discussion or issue with the
relevant template. Include your operating system, Python version, host, the generated configuration
from `python3 scripts/board.py mcp-config --json` with private paths redacted, and a reproducible
command where possible.

Use the source-dispute form when a marker or attributed source appears wrong. Do not post private
corpora, session transcripts, API keys, or personal decision records.

Security vulnerabilities and suspected data exposures must not be filed publicly. Follow
[SECURITY.en.md](SECURITY.en.md) instead.

This is an early-access project; support is best-effort and no response-time commitment is made.
