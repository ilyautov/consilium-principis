# Лендинг Consilium-Principis — дизайн

> Брейншторм 2026-07-16. Прямое продолжение дня, в котором ров четыре раза подряд ответил
> «чинить нечего» (квота, рычаг, HyDE, гибрид — все ноль). Вывод: технический риск больше не
> главный, следующий рубеж — рыночный.

## 1. Зачем и что меряем

**Задача — не продать, а измерить: доходят ли люди до пробы.**

Метрика-ответ: **сколько человек из пришедших скопировали команду установки**. Всё остальное
(визиты, досмотр демо, уход на GitHub) — контекст, объясняющий, ГДЕ отвалились.

**Чего лендинг НЕ меряет (зафиксировано явно, чтобы потом не обмануться).** Он не меряет
готовность платить. Изначально предлагался fake-door прайс, и он отвергнут по делу: тарифов
(аудит-лог, RBAC) не существует, рисовать цены на несуществующее — мерить фантазию и давать
обещание, которого мы не держим. WTP остаётся открытым и закроется позже, когда будет что
продавать. Через месяц не решить, что мы его уже проверили.

**Почему не waitlist.** Подписаться бесплатно люди готовы охотно — это меряет вежливость, не
спрос. Проба требует усилия, поэтому она и есть сигнал.

## 2. Блокер (кнопка Ильи)

**Лендинг нельзя пускать в трафик, пока основной репозиторий приватный.** CTA — это
`/plugin marketplace add ilyautov/consilium-principis`; на приватном репо команда не сработает.
Человек придёт, вдохновится, скопирует, получит ошибку — хуже, чем не приходить вовсе.

Строить и деплоить страницу можно до флипа. Пускать трафик — только после.

Второй риск того же рода: **лендинг без трафика ничего не измерит.** Ноль визитов — это не
ответ «рынка нет», это отсутствие замера. Источник трафика (Show HN / MCP-каталоги / X) —
отдельная работа, не часть этой спеки, но без неё спека бессмысленна.

## 3. Аудитория и язык

- **Основная:** разработчики с Claude Code / MCP. Язык — **English**, путь `/`.
- **Вторая:** русскоязычная аудитория Ильи. Путь `/ru`.
- Приоритет трафика — EN (Show HN, MCP-каталоги, X англоязычны). RU — личные каналы.

## 4. Структура (Minimal Single Column, один CTA)

1. **Hero** — заголовок, демо-видео, один CTA.
2. **TierExplainer** — три тира как реальный вывод продукта.
3. **HonestLimits** — чего продукт не умеет.
4. **Install** — одна команда, копирование в буфер.
5. **Footer** — GitHub, лицензия MIT, переключатель `/ru` ↔ `/`.

Намеренно **отсутствуют**: цены (продавать нечего), waitlist-форма (меряем пробу), отзывы
(их нет — рисовать нельзя), навигационное меню (одна страница, один CTA).

### 4.1 Hero

Заголовок без суперлативов (GTM-ресёрч: скромный язык сильнее; «fastest/first/best» —
антипаттерн для HN):

- EN: **An AI council that cites verbatim — or refuses to answer**
- RU: **Совет советников, который докажет цитату или откажется отвечать**

Подзаголовок:

- EN: Advisors grounded in the actual texts of real thinkers. Every quote is verified
  character-by-character against the source — in code, not by the model's word.
- RU: Советники, заземлённые на подлинные тексты реальных мыслителей. Каждая цитата сверяется
  с источником посимвольно — кодом, а не на слово модели.

Ниже — демо-видео (см. §6). Один CTA, ведёт к §Install (якорь на той же странице, не наружу).

### 4.2 TierExplainer

Три тира показываются **как терминальный вывод**, а не как декоративные буллеты:

- 🔵 — дословная цитата, сверена с источником посимвольно;
- 🟢 — комментарий/пересказ, заземлён, но не дословен;
- 🟡 — экстраполяция: советник рассуждает за пределами текста, и это помечено.

Отличие, которое здесь проговаривается: **сверка посимвольная кодом**, а не «источник назван».
Это единственное, что по конкурентному рефрешу осталось уникальным (grounding+fail-closed уже
делят World Bank AVA и PersonaCite).

### 4.3 HonestLimits

Не скромность, а отстройка. Инкумбенты обещают hallucination-free и не держат (Stanford RegLab:
17–33% галлюцинаций у Lexis/Westlaw). Мы выигрываем тем, что говорим, чего не умеем:

- корпус собираешь сам — мы не поставляем тексты;
- нужен Claude Code (или другой MCP-хост);
- советники — только public domain;
- советник **откажется** отвечать, если основания нет. Это фича, и она будет раздражать.

### 4.4 Install

Две команды, каждая копируется по клику:

```
/plugin marketplace add ilyautov/consilium-principis
/plugin install consilium-principis@consilium-marketplace
```

Ниже — одна строка про то, что дальше: советники из public domain собираются командой
`seed_council`, ollama не обязательна (без неё работает лексический ретрив).

## 5. Дизайн-система

Из `ui-ux-pro-max --design-system` (продукт: developer tool, open-source, verification):
паттерн **Minimal Single Column**, стиль **Dark Mode (OLED)**, шрифт **Inter**.

| Токен | Значение |
|---|---|
| `--color-background` | `#0F172A` |
| `--color-foreground` | `#F8FAFC` |
| `--color-muted` | `#272F42` |
| `--color-border` | `#475569` |
| `--color-primary` | `#1E293B` |

**Отклонение от рекомендации скилла — обязательное.** Скилл предлагает акцент/CTA `#22C55E`
(зелёный). **Нам нельзя.** У нас цвет — это данные, а не украшение: 🔵 дословно, 🟢 комментарий,
🟡 экстраполяция. Зелёная кнопка «Установить» размывает ровно ту семантику, которую продукт
продаёт как главное отличие. То же с красным `#EF4444` для ошибок: рядом с жёлтым он читается
как продолжение шкалы тиров.

**Правило:** синий / зелёный / жёлтый — заповедник тиров, в UI-хроме не используются. CTA берёт
нейтральный тон вне шкалы: светлый `#F8FAFC` на тёмном фоне (контраст 7:1+, максимальная
заметность, ноль коллизий со смыслом).

**Эмодзи.** Правило скилла «никаких эмодзи вместо иконок» соблюдается: 🔵🟢🟡 живут только внутри
демо-блока и TierExplainer как **реальный вывод продукта**. В кнопках, навигации и буллетах —
SVG (Lucide) либо ничего.

Тема только тёмная, без переключателя: аудитория — разработчики, а светлая версия удвоит работу
над контрастом ради никого.

## 6. Демо (главный элемент)

Записывается **VHS** (charmbracelet): один `.tape` → `demo.webm` + `demo.mp4` + `demo.gif` +
`poster.png`. Живёт в репозитории лендинга, версионируется.

Сценарий, ~8 секунд, два контрастных кадра:

1. запрос, на который основание есть → 🔵 дословная цитата + источник (книга, глава);
2. запрос, на который основания нет → честный отказ.

Это форма aha по разведке демо: **«докажет или откажется блефовать»**, а не «N мнений сходятся».
Никто из 7 конкурентов не показывает честное воздержание — это наше белое пятно.

**На странице — `<video>`, не GIF:** 8 секунд терминала в GIF весят мегабайты, в WebM/MP4 — в
разы меньше при лучшей чёткости. GIF всё равно нужен (README, X), поэтому пайплайн отдаёт оба.

**Reduced-motion — обязательный кейс, а не галочка.** Автоплей GIF нельзя остановить, для
человека с вестибулярными нарушениями это ловушка. Поэтому: `<video autoplay loop muted
playsinline poster="poster.png">`, а при `prefers-reduced-motion: reduce` автоплей отключается
и показывается постер с кнопкой воспроизведения.

**Запись — настоящая.** Если живой прогон выглядит хуже макета — это сигнал о продукте, а не
повод дорисовать кадр.

## 7. Аналитика

**Umami Cloud** — бесплатный тариф покрывает наш масштаб с запасом, без куки → без баннера
согласия → первый экран не испорчен. Plausible — платная альтернатива (~$9/мес) с тем же
интерфейсом событий; переезд стоит одной замены скрипта, поэтому выбор не влияет на дизайн.
Google Analytics отвергнут: при privacy-first позиционировании это лицемерие.

События воронки:

| Событие | Смысл |
|---|---|
| `pageview` | пришёл |
| `demo_played` | демо реально посмотрели (для reduced-motion — клик по play) |
| `install_visible` | доскроллил до блока установки |
| `copy_install` | **скопировал команду — главное число** |
| `github_click` | ушёл в репозиторий |

**Абсолютного порога у нас нет, и выдумывать его нельзя.** Отраслевые бенчмарки конверсии
(3% / 5%) в нашем же монетизац-ресёрче помечены REFUTED (0-3) и запрещены к цитированию;
любое «должно быть N%» будет правдоподобным числом, выдающим себя за знание. Тот же урок, что
`n<8 → вердикта нет`: лучше отказаться от вердикта, чем произвести уверенный ложный.

Поэтому читаем **не абсолют, а форму воронки** — она информативна и при малом n:

- отваливаются на геро (`demo_played` низкий) → не поняли/не поверили оффер;
- смотрят демо, но не доходят до установки → аха есть, ценности нет;
- доходят и не копируют → цена входа (свой корпус, Claude Code) выше желания;
- копируют → болевой якорь есть, дальше меряем удержание, а не лендинг.

Абсолютный порог назначаем после первых ≥200 визитов, глядя на реальное распределение, и
фиксируем письменно ДО следующего изменения страницы — иначе будем подгонять вывод под
результат.

## 8. Архитектура

**Отдельный публичный репозиторий `consilium-landing`**, не папка в основном. Основной репо
приватный и содержит частные корпуса, купленные книги живых авторов и слаги приватных
советников. Отдельный репо делает утечку невозможной физически, а не по внимательности.

- Next.js, статический экспорт (`output: 'export'`), TypeScript, Tailwind.
- Деплой: Netlify.
- Две страницы: `/` (EN), `/ru` (RU). **Без i18n-библиотеки** — для двух страниц это лишняя
  абстракция; тексты лежат в двух модулях-константах.
- Бэкенда нет. Форм нет. Состояние — только «скопировано» в `Install`.

## 9. Компоненты

| Компонент | Ответственность | Состояние |
|---|---|---|
| `Hero` | заголовок, подзаголовок, `<Demo>`, CTA-якорь | нет |
| `Demo` | video + poster + reduced-motion | `playing` |
| `TierExplainer` | три тира как вывод продукта | нет |
| `HonestLimits` | ограничения списком | нет |
| `Install` | две команды + копирование | `copied` |
| `Footer` | GitHub, MIT, переключатель языка | нет |

Тексты — не внутри компонентов: `content/en.ts`, `content/ru.ts`. Компонент получает контент
пропсом, поэтому обе страницы используют одни и те же компоненты, а перевод не требует правки
разметки.

## 10. Краевые случаи

| Ситуация | Поведение |
|---|---|
| Видео не загрузилось | остаётся `poster.png` — смысл кадра читается статикой |
| `prefers-reduced-motion` | автоплей выключен, постер + кнопка play |
| Clipboard API недоступен / нет HTTPS | текст команды выделяется, не «молча ничего» |
| JS отключён | страница читается целиком: текст, команды, постер (статический экспорт) |
| Аналитика заблокирована адблоком | страница работает; в воронке недоучёт — принимаем осознанно |

## 11. Приёмка

- Контраст: пары текста на `#0F172A` ≥ 4.5:1 (проверить инструментом, не на глаз).
- Верстка: 375 / 768 / 1024 / 1440, без горизонтального скролла.
- `prefers-reduced-motion`: автоплея нет.
- Без JS: текст и обе команды читаются.
- Тир-цвета не встречаются в UI-хроме (кнопки/ссылки/бордеры) — регресс-гард замыслен как
  ревью-чеклист, автотест на это не строим (YAGNI).
- Вес первого экрана: видео ≤ 1 МБ.
- Клавиатура: CTA и кнопки копирования достижимы табом, фокус виден.

## 12. Что НЕ делаем (YAGNI)

Цены и тарифы; waitlist и любые формы; отзывы; блог; переключатель темы; i18n-библиотека;
собственный счётчик на Netlify Functions (своя система ради четырёх чисел); A/B заголовков
(при нашем трафике не наберётся статзначимости — тот же урок, что `n<8 → вердикта нет`).

## 13. Открытые вопросы

2. **Источник трафика** — Show HN / MCP-каталоги / X. Без него замера не будет; отдельная работа.
3. **Домен** — не выбран. Netlify-поддомен годится для первого замера.
