# Как контрибьютить в Consilium-Principis

> [English](CONTRIBUTING.en.md) · **Русский**

Спасибо за интерес. Проект небольшой и держится на нескольких инвариантах; если их уважать,
PR примут быстро. Прочитайте два красных правила ниже до первого коммита.

## 🚫 Два правила, которые нельзя нарушать

### 1. Только public-domain. Копирайтные тексты никогда.

Ценность проекта в заземлении персон в **подлинных, легально свободных** текстах. В репозиторий
попадают ТОЛЬКО материалы в общественном достоянии (Сунь-цзы, Марк Аврелий, Эпиктет, Макиавелли
и т.п., обычно из [Project Gutenberg](https://www.gutenberg.org)).

- **Не добавляйте** книги/переводы под копирайтом, даже отрывками. Современные фигуры каждый
  собирает из **своих легальных материалов локально**, это не обсуждается и не мержится.
- Ваша личная доска (`advisors/`), заседания (`council/`), локальные реестры это **личные данные**,
  они в `.gitignore` и не должны попадать в коммиты. Проверьте `git status` перед push.

### 2. Защитный контур fail-closed. Не ослабляйте гейт.

«LLM рассуждает, код решает». Метка 🔵 (дословная цитата) выдаётся **только** при верификации кодом,
а воздержание при сомнении это фича, не баг. PR, который заставляет систему цитировать
неверифицированное, смягчает abstention или пропускает топически-близкое-но-не-отвечающее за 🔵,
будет отклонён. Меняете что-то рядом с гейтом верности, приложите тест, доказывающий, что честность
не просела.

## Как устроена работа

**TDD, каждый раз.** Красный тест → минимальная реализация → зелёный → коммит. Тесты идут не после,
а вперёд поведения. Багфиксы начинаются с теста, воспроизводящего баг.

### Язык и исходники

Английский — канонический язык коммитов, кода, схем и технической документации, на которую
ссылаются как на норму. Поддерживаемые русские точки входа (`README.ru.md`, `QUICKSTART.md` и
документы подключения) обновляются вместе с соответствующим английским описанием: они не
переводят канон задним числом и не обещают другой путь установки или уровень поддержки.

Тексты корпуса остаются на языке источника. Не переводите и не «улучшайте» их в составе корпуса:
перевод может быть пояснением рядом, но не заменой первоисточника для проверки цитат.

Используйте English Conventional Commits, например `docs: clarify privacy boundary` или
`fix: reject empty source marker`.

**Оффлайн-инвариант это святое.** Весь сьют обязан проходить без сети, без ollama, без внешнего
движка и без ключей (так его видит внешний пользователь и CI). Запуск ровно так:

```bash
HEPHAESTUS_ENGINE=/nonexistent OLLAMA_HOST=http://127.0.0.1:59999 python3 -m pytest tests/ -q
```

Или короче: `make test`. Тест, который ходит в сеть без DI-инъекции фейка, в CI не пройдёт.
Единственное известное env-хрупкое исключение это `test_ssrf_check_passes_public_blocks_private`
(зависит от локального DNS); его расхождение можно игнорировать.

**Ничего лишнего.** DRY, YAGNI. Не рефакторьте несвязанное в том же PR.

## Локальная настройка

```bash
git clone https://github.com/ilyautov/consilium-principis
cd consilium-principis
python3 -m pip install pytest numpy      # ядро на stdlib; это для тестов и семантики
python3 install.py                       # самопроверка (копия в ~/.claude/skills/)
make test                                # оффлайн-сьют
```

Нужен только **Python 3.10+**. Умный кросс-язычный поиск опционален
([ollama](https://ollama.com) + `bge-m3`); без него контур работает на лексическом полу.

## Само-документация не должна дрейфовать

Часть документации генерируется из кода (`docs/selfdoc/index.json` → `docs/MANUAL.md`, рантайм-тул
`explain_self`). Если добавили/переименовали тул, правило или тест, перегенерируйте и закоммитьте
вместе с изменением, иначе гард свежести уронит CI:

```bash
python3 scripts/gen_selfdoc.py && python3 scripts/build_manual.py
```

## Чек-лист перед PR

- [ ] Ноль копирайтных текстов; ноль личных данных (`advisors/`, `council/`, `.env`, `*.local.json`)
- [ ] `make test` зелёный офлайн (кроме env-хрупкого SSRF-теста)
- [ ] Новое поведение покрыто тестом (написан ДО реализации)
- [ ] Если тронут гейт верности, есть тест, что честность не ослабла
- [ ] Selfdoc перегенерирован, если менялись тулы/правила/тесты
- [ ] English Conventional Commit, без секретов в diff и в истории
