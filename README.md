# Consilium Principis

**Совет перспектив для одного решения.**

Личный совет директоров из AI-персон реальных мыслителей — грунтованных в их же текстах,
с защитным контуром против выдумки.

</div>

---

## Что это

Навык для Claude (Code / Desktop / Cowork): ты созываешь **совет** — несколько советников,
каждый говорит голосом реального мыслителя, опираясь на его подлинный корпус. Они обращаются
к тебе, **спорят между собой**, дают синтез и шаг к действию.

Это не «чат-бот в роли мудреца». Разница — в **защитном контуре**:

| Маркер | Что значит |
|---|---|
| 🔵 | **дословная цитата** из верифицированного корпуса (проверяется посимвольно) |
| 🟡 | **перенос** — мысль в духе автора, но не его точные слова |
| *отказ* | вопрос вне корпуса → советник **честно молчит**, а не фантазирует |

Плюс встроенная **анти-лесть**: советник держит свою линзу и скорее оспорит, чем поддакнет.
Контур работает **на любом уровне установки** — деградирует только меткость поиска, не честность.

## Два уровня (выбираются сами)

- **Пол (SIMPLE)** — лексический поиск + контур. Нужен только **Python 3.10+**. Ноль установки, ноль ключей.
- **FULL** — семантический поиск (bge-m3 через [ollama](https://ollama.com)). Опционально, для большого корпуса.

Никаких аккаунтов и API-ключей. Пол — честный минимум, а не урезанная версия.

## Быстрый старт

### Самое простое — поставит сам Claude (по ссылке)

Открой Claude Code и скажи, дав ссылку на этот репозиторий:

> «Поставь мне этот навык: https://github.com/ilyautov/consilium-principis»

Claude сам сделает: `git clone` → `python3 install.py` (скопирует в `~/.claude/skills/`,
определит тир, запустит самопроверку `doctor`) → отчёт о здоровье. Ключи и терминал не нужны.
Дальше скажи **«с чего начать»** (соберёт стартовый совет) или **«что умеешь?»** (меню рецептов).

Что Claude выполняет под капотом (можешь дать это как инструкцию, если он не понял с первого раза):
```bash
git clone https://github.com/ilyautov/consilium-principis ~/consilium-principis
cd ~/consilium-principis && python3 install.py        # копия в ~/.claude/skills + самопроверка
```

### Другие пути

Три пути целиком — в [`QUICKSTART.md`](QUICKSTART.md): (1) попросить Claude (выше),
(2) клик-установщик ([`install.command`](install.command) / `.bat` / `.sh`), (3) терминал.
Пустая доска — норма; первого советника соберёшь за руку.

## Собери свой совет

**Доска пустая из коробки — это норма.** Совет личный; кого посадить — выбираешь ты.
Рецепт сборки советника (найти источник → построить корпус → написать профиль →
**проверить каждую цитату контуром** → eval) — в [`install-skill/SKILL.md`](install-skill/SKILL.md)
и [`advisors/README.md`](advisors/README.md).

> ⚖️ **Граница.** Навык не качает копирайтные книги. Public-domain тексты тянутся свободно;
> копирайт — только твои легальные копии. Твоя доска (`advisors/`) — личные данные, не уходят в репозиторий.

## Как устроено

Движок — адаптер с тремя сменными бэкендами под единым контрактом (лексический пол →
семантический → удалённый), с мягкой деградацией. Защитный контур (verbatim-гейт цитат)
не зависит от бэкенда. Подробности — `SKILL.md` и
[`docs/`](docs/superpowers/specs/).
