# Лендинг Consilium-Principis — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Публичная страница, которая показывает аха («докажет цитату или откажется блефовать») и меряет, сколько людей доходят до копирования команды установки.

**Architecture:** Отдельный публичный репозиторий `consilium-landing` (основной приватный и держит купленные книги + слаги приватных советников — отдельный репо исключает утечку физически). Next.js static export, без бэкенда и форм. Две страницы `/` (EN) и `/ru` используют ОДНИ компоненты; тексты вынесены в `content/en.ts` / `content/ru.ts` и приходят пропсом.

**Tech Stack:** Next.js 15 (`output: 'export'`), TypeScript, Tailwind v4, Vitest + Testing Library + jsdom, Umami Cloud, VHS (демо), Netlify.

**Спека:** `docs/superpowers/specs/2026-07-16-landing-design.md` (master cc5c939).

**Путь репозитория:** `/Users/ilyautov/personal/Projects/consilium-landing`

**Блокеры (кнопки Ильи, в план НЕ входят):** флип основного репо в public — до него трафик пускать нельзя, CTA приведёт в ошибку; источник трафика (Show HN / MCP-каталоги / X) — без него замера не будет.

```ts
/** Единая точка событий. Umami режется адблоком — тогда просто молчим: страница важнее замера. */
export const EVENTS = {
  demoPlayed: "demo_played",
  installVisible: "install_visible",
  copyInstall: "copy_install", // ГЛАВНОЕ ЧИСЛО: дошёл ли человек до пробы
  githubClick: "github_click",
} as const;

export type EventName = (typeof EVENTS)[keyof typeof EVENTS];

export function track(event: EventName): void {
  if (typeof window === "undefined") return;
  const umami = (window as unknown as { umami?: { track: (e: string) => void } }).umami;
  umami?.track(event);
}
```

```tsx
"use client";
import { useEffect, useRef, useState } from "react";
import { track, EVENTS } from "@/lib/analytics";

/** Демо продукта. GIF отвергнут: 8 сек терминала в GIF — мегабайты, и его НЕЛЬЗЯ остановить,
 *  что делает автоплей ловушкой при вестибулярных нарушениях. Video + poster решает оба. */
export default function Demo({ label }: { label: string }) {
  const [reduced, setReduced] = useState(false);
  const ref = useRef<HTMLVideoElement>(null);

  useEffect(() => {
    setReduced(window.matchMedia?.("(prefers-reduced-motion: reduce)").matches ?? false);
  }, []);

  const play = () => {
    ref.current?.play();
    track(EVENTS.demoPlayed);
  };

  return (
    <figure className="relative w-full max-w-3xl rounded-lg border border-[var(--color-border)] overflow-hidden">
      <video
        ref={ref}
        poster="/poster.png"
        aria-label={label}
        loop
        muted
        playsInline
        {...(reduced ? {} : { autoPlay: true })}
        onPlay={() => track(EVENTS.demoPlayed)}
        className="block w-full"
      >
        <source src="/demo.webm" type="video/webm" />
        <source src="/demo.mp4" type="video/mp4" />
      </video>
      {reduced && (
        <button
          onClick={play}
          className="absolute inset-0 grid place-items-center bg-[var(--color-bg)]/60 text-[var(--color-fg)] font-medium cursor-pointer"
        >
          Play demo
        </button>
      )}
    </figure>
  );
}
```

```tsx
"use client";
import { useRef, useState } from "react";
import { track, EVENTS } from "@/lib/analytics";
import type { PageContent } from "@/content/types";

export default function Install({ content }: { content: PageContent["install"] }) {
  const [copied, setCopied] = useState<number | null>(null);
  const refs = useRef<(HTMLElement | null)[]>([]);

  /** Clipboard требует HTTPS и разрешения. Недоступен — выделяем текст: человек скопирует
   *  руками. Молчащая кнопка хуже отсутствующей. */
  const copy = async (text: string, i: number) => {
    try {
      await navigator.clipboard.writeText(text);
      setCopied(i);
      setTimeout(() => setCopied(null), 2000);
    } catch {
      const node = refs.current[i];
      if (node) {
        const range = document.createRange();
        range.selectNodeContents(node);
        const sel = window.getSelection();
        sel?.removeAllRanges();
        sel?.addRange(range);
      }
    }
    track(EVENTS.copyInstall);
  };

  return (
    <section id="install" className="w-full max-w-3xl">
      <h2 className="text-2xl font-semibold mb-4">{content.title}</h2>
      {content.commands.map((cmd, i) => (
        <div key={cmd} className="flex items-center gap-3 mb-3">
          <code
            ref={(el) => { refs.current[i] = el; }}
            className="flex-1 rounded bg-[var(--color-muted)] px-4 py-3 font-mono text-sm overflow-x-auto"
          >
            {cmd}
          </code>
          <button
            onClick={() => copy(cmd, i)}
            aria-label={`Copy: ${cmd}`}
            className="shrink-0 rounded border border-[var(--color-border)] px-4 py-3 text-sm font-medium cursor-pointer transition-colors duration-200 hover:bg-[var(--color-muted)] focus-visible:outline-2 focus-visible:outline-[var(--color-fg)]"
          >
            {copied === i ? content.copied : "Copy"}
          </button>
        </div>
      ))}
      <p className="mt-4 text-sm text-[var(--color-fg)]/70">{content.after}</p>
    </section>
  );
}
```
