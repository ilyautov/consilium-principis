- **Верность (C1/H2):** 🔵 требует ≥3 слов и отклоняет обрезку, рвущую отрицание (было: одиночное слово / вырванный фрагмент проходили как 🔵).
- **Безопасность (H5):** read-side path-traversal гард — любой путь (abs и rel) клампится к корню репо (закрыт arbitrary-file-read через host-exposed тулы).
- **Приватность (H4):** судья релевантности остаётся локальным даже при `LLM_BACKEND=openrouter` (корпус не утекает в облако).
- **Массовый путь (C3/C4/C5):** краш рендера без синтеза; таймаут судьи (num_predict); O(cand×корпус) ре-сканы (mtime-кеш).
- **DRY (H6):** единый `marker_status` — один источник ядрового инварианта.
- **Тесты (H8/H9):** numpy-optional сбор; покрытие eval-харнесса.
- **Доки (H11/H12):** актуализированы счётчики (правила 0-17, 60 тулов); тиры честно (RRF opt-in, строго хуже кросс-язычного).

## [0.1.0] — 2026-07-08

Первый публичный ранний доступ. Базовая линия: заседания совета + защитный контур верности,
работающие офлайн на чистом stdlib.

### Возможности

- **Совет-заседание** — советники обращаются к пользователю, спорят между собой, дают синтез и
  один шаг к действию; интерактивный «живой круглый стол» как отдельный режим.
- **Защитный контур верности** — маркеры 🔵 (дословная цитата, сверена с первоисточником) / 🟢
  (комментарий) / 🟡 (мысль в духе автора) / 📐 (расчёт); **fail-closed воздержание** — вне корпуса
  советник молчит, а не сочиняет. Двухфазный судья-гейт релевантности (модель судит, код применяет порог).
- **Ров против камуфляжа** — топически-близкое-но-не-отвечающее не проходит за 🔵 (borderline-gated судья).
- **📐 Карта решения + Монте-Карло** — на считаемом вопросе совет раскладывает выбор на числа
  (тройки худший/типичный/лучший против якорения) и прогоняет детерминированный Монте-Карло
  (ноль LLM в счёте, сид → воспроизводимость); торнадо чувствительности, обязательный вариант
  «ничего не делать», петля исхода (сверка прогноза с фактом).
- **Три тира поиска** — от чистого Python (лексический, под русскую морфологию) до семантического
  (ollama + `bge-m3`) с мягкой деградацией; контур одинаково честен на любом тире.
- **Каталог public-domain фигур** + guided-сборка совета из общественного достояния (cold-start).
- **MCP-сервер** — весь цикл (сборка, заседания, виджеты) доступен тулами в любом MCP-хосте.
- **Само-документация** — `docs/MANUAL.md` генерируется из кода; рантайм-тул `explain_self`;
  гарды свежести ловят дрейф в CI.
- **Линзы** — методы/подходы поверх персон (напр. frame-линза «Стратег (McKinsey)»).

### Гарантии

- Весь сьют (1000+ тестов) проходит **офлайн** — без сети, ollama, внешнего движка и ключей;
  CI гоняет на Python 3.10/3.11/3.12.
- Личные данные (доска, заседания, реестры, `.env`) в `.gitignore` и не входят в поставку.
